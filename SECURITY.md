# Security policy

Report vulnerabilities privately to security@hybridcloudworks.com (or via GitHub private vulnerability reporting). Please do not open public issues for security findings. Expect an acknowledgement within 3 business days.

Scope highlights: the demo processes sensitive infrastructure inventories in memory only, never connects to Azure, and
has no execution surface; see `docs/security/threat-model.md`. Supported version: `main`. The Azure appliance is a separate repository with its own policy: https://github.com/saulpatinojr/HCW-AzMigrateOrchestrator_App/blob/main/SECURITY.md
