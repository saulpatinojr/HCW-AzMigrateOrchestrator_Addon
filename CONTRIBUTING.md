# Contributing

1. Fork/branch, `npm run app:bootstrap` (upstream at the pinned release), `npm ci`, make the change, `npm test`, `npm run e2e`.
2. Engine, rule and UI-component changes are made upstream in `saulpatinojr/HCW-AzMigrateOrchestrator_App`; this edition adopts releases through the `core-update` pull requests.
3. Fill the PR template honestly: what you ran, what you did not, and why.
4. Keep `VALIDATION.md` current; edition-relevant ADRs are copied from upstream.
5. Be kind; see `CODE_OF_CONDUCT.md`.
