# ADRs

The canonical, complete ADR log for both repositories lives upstream in `saulpatinojr/HCW-AzMigrateOrchestrator_App` (`docs/adr/`). The files here are copies of the decisions that shape the web-front edition. New ADRs are numbered in the shared sequence and recorded upstream first (ADR-0028).

[ADR-0030](ADR-0030-web-front-edition-runs-as-a-site-pane.md) "the web-front edition runs as a site pane" is copied here from
upstream (accepted 2026-10-10). It supersedes ADR-0028's consequence that the website installs the UI package; the pane model
is described by `docs/website-integration/integration-guide.md` and the HCW AddOn Integration Standard in the website
repository. The "ADR-0032 / LAB-5" cited by the Coder template is the website's lab-host decision, not part of this numbering.
