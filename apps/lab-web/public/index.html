Azure Resource Assessment Demo

Upload the resources.csv you export from the Azure portal and see how each resource would move: native ARM move, Azure Resource Mover, a migration service, or recreate-and-migrate with a separate data path.

What this demo is — and is not. This explorer analyses an exported inventory only. It never connects to an Azure tenant, never asks for credentials, and cannot execute migration actions. Results are rule-based illustrations labelled with their evidence state and confidence; they are not an authoritative Azure assessment. Uploads are processed in memory and expire automatically.
